##Econofísica Orbital: Evaluando la Riqueza Global a través de Emisiones Lumínicas Nocturnas.

## Objetivo del Proyecto
Evaluación de la luminosidad nocturna satelital como métrica alternativa para validar el crecimiento económico. El objetivo es detectar posibles distorsiones o manipulaciones en el PBI oficial mediante el cruce de datos espaciales y variables macroeconómicas.

## Fuentes de Datos
1. **Luminosidad Satelital:** VIIRS Nighttime Lights (Promedio de radiancia por país).
2. **Macroeconomía:** Banco Mundial (PBI per cápita en US$ corrientes y clasificación de ingresos).

## Metodología y Stack Tecnológico
* **Lenguaje:** Python 3.x
* **Estandarización de datos:** Unificación relacional mediante códigos ISO-3 (Pandas/NumPy).
* **Visualización:** Distribuciones asimétricas y diagramas de dispersión con transformaciones logarítmicas (Matplotlib/Seaborn).
